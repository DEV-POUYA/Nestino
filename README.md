🏨 Nestino
Find your perfect stay.
Nestino is a hotel booking web application built with Next.js, designed to help users explore rooms, choose their stay dates, and manage guest details through a clean, responsive interface.

✨ Features
- 🛏️ Room Discovery
- 📅 Check-in, check-out and guest selection
- ⚛️ State management with Redux Toolkit
- 🗄️ MongoDB integration with Mongoose
- 📱 Responsive user interface

🛠️ Tech Stack
Next.js
React
Tailwind CSS
Redux Toolkit
MongoDB
Mongoose


🚀 Getting Started
git clone https://github.com/DEV-POUYA/Nestino.git
cd Nestino
npm install
npm run dev
